## Descripción del Programa
Programa de consola desarrollado en Java que solicita datos
personales del estudiante (nombre, carné, año de nacimiento y año actual) para
realizar cálculos que  determinen de
forma aproximada su edad en años, su equivalente en meses, y comprobar si es
mayor de edad.

## Datos Solicitados
- Nombre completo del estudiante
- Carné
- Año de nacimiento
- Año actual

## Cálculos Realizados
- **Edad aproximada:** Resta del año actual menos el año de
  nacimiento (`anioActual - anioNacimiento`).
- **Edad aproximada en meses:** Multiplicación de la edad
  aproximada por 12 (`edadAproximada * 12`).
- **Mayoría de edad:** Comparación lógica para evaluar si la
  edad es mayor o igual a 18 (`edadAproximada >= 18`).
